# Ejercicio 6 - Polimorfismo via interfaces

Simulador de integraciones de pagos, logistica y FEL, en Java de consola. No utiliza APIs reales.

## Estructura
- `docs/`: analisis Excel, UML editable y enunciado.
- `src/`: codigo Java.
- `bin/`: archivos `.class` compilados.

## Ejecutar (desde la carpeta raiz)
```bash
javac -d bin src/*.java
java -cp bin Principal
```
